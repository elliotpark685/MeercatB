# 3. Information Architecture (IA)

> 서비스의 전체 메뉴 구조와 페이지 계층을 정의합니다.

---

## 3.1. Public Pages (로그인 전)

- `/`: Landing Page (서비스 소개)
- `/pricing`: 요금제
- `/about`: 서비스 상세 소개
- `/contact`: 문의
- `/terms`: 이용약관
- `/privacy`: 개인정보처리방침
- `/disclaimer`: AI 면책조항
- `/login`: 로그인
- `/signup`: 회원가입
- `/knowledge`: 안전 지식 (블로그, 가이드 등) - **(신규)**
- `/updates`: 법령/서비스 업데이트 소식 - **(신규)**

## 3.2. Protected Pages (로그인 후)

- `/app/search`: 통합 검색 (로그인 후 첫 화면)
- `/app/dashboard`: 관리자 대시보드
- `/app/laws`: 법령 검색 (상세)
- `/app/safety-standards`: 안전기준 검색 (상세)
- `/app/kosha-guide`: KOSHA GUIDE 검색 (상세)
- `/app/documents`: AI 문서 생성
- `/app/todos`: 나의 할 일
- `/app/regulations`: 법령/안전기준 수집 현황
- `/app/settings`: 계정 설정
