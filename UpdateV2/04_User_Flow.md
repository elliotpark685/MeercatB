# 4. User Flow

> 사용자가 서비스 내에서 목표를 달성하기 위해 거치는 주요 경로를 시각화합니다.

---

## 4.1. 핵심 사용자 시나리오: "고소작업 계획서 초안 작성"

1.  **회원가입 / 로그인**
    - 사용자가 서비스에 접근하여 계정을 생성하거나 로그인합니다.

2.  **통합 검색**
    - `"고소작업 추락 방지"`와 같은 키워드로 검색합니다.

3.  **AI 답변 및 법령 확인**
    - AI가 요약한 답변과 함께 관련 법령, 안전기준, KOSHA GUIDE 검색 결과를 확인합니다.
    - `산업안전보건기준에 관한 규칙 제XX조` 등 핵심 근거를 인지합니다.

4.  **문서 생성**
    - '문서 생성' 페이지로 이동하여 '작업계획서' 유형을 선택합니다.
    - 작업명: `외부 비계 해체 작업`, 키워드: `고소작업, 추락, 보호구` 등을 입력합니다.

5.  **결과 확인 및 저장**
    - AI가 생성한 작업계획서 초안을 확인하고, 필요한 부분을 수정합니다.
    - 결과물을 시스템에 저장하거나 PDF로 다운로드합니다.

6.  **결제 (향후)**
    - 월간 생성 한도를 초과하거나 Pro 기능을 사용하기 위해 구독 플랜을 결제합니다.
